# 《浣熊火箭：无名氏危机》开发进度

- 更新时间：2026-11-18
- 当前版本：0.1.0（第一幕 MVP）
- 仓库：https://github.com/hahaandxixi/Qoder-competition
- 形态：Phaser 3 + Vite + TypeScript，纯静态站点，无后端、数据库、外部 CDN

## 1. 当前结论

第一幕已经形成可玩的完整闭环：

**标题 → 第一幕跑跳/射击 → 名字门四选一 → 三选一签收梗卡 → 甄领先 Boss 战（3 阶段）→ 2 秒认梗弹反 → 胜利/失败 → 重试/返回标题 → 档案与声明**

`npm run build` 已在本机成功生成 `dist/`，TypeScript 严格检查通过。尚未部署到 Qoder Sites，因此当前不能声称已有公网试玩地址。

## 2. 已实现内容

### 2.1 玩法

- 左右移动、二段跳、土狼时间/跳跃缓冲、射击、冲刺（带无敌帧与残影）
- 浣熊阿浣、负鼠巡逻兵、龙虾炮台、Boss 甄领先（电视头发布会造型）全部为代码绘制的像素风程序化贴图
- 第一幕横向关卡：地面分段、约 20 个平台、8 个敌人、故障陷阱、检查点、教学牌、名字门、Boss 入口
- 名字门：4 选 1、30 秒、答错可重试，答对回血 30% 并进入三选一梗卡签收
- Boss 战：3 个阶段，技能包含瞄准弹、数据雨、冲刺/红毯冲刺；答题时战斗不暂停
- 认梗弹反：2 秒窗口、3 个选项、1/2/3 或点击作答；答对 = 完美弹反 + Boss 硬直 + 反伤 + 掉卡；答错/超时 = 扣血 + 显示正确答案
- 梗浓度槽：答对累积，连对加成，满槽进入 5 秒双倍伤害爆发
- 8 张梗卡，三格签收袋；键盘 Z/X/C 或点击卡槽使用；满袋时替换最旧卡
- 胜负结算、最佳记录、重试/返回、制作与合规声明
- 桌面键盘和手机触屏双输入：手机端含左/右、射击、跳跃、冲刺、交互键；答题与梗卡可直接点选

### 2.2 内容与安全

- 题库 12 道（6 道弹反题 + 6 道名字门题），全部在 `src/data/questions.json`
- 梗卡 8 张，全部在 `src/data/cards.json`；Boss 阶段/题池/台词在 `src/data/bosses.json`；UI 文案集中在 `src/data/strings.json`
- 所有角色、公司、事件均为虚构戏仿；未使用真实姓名、真实公司、商标、Logo、真人肖像、短视频原声/原画面/长段台词
- 美术与音效均由代码生成；字体使用设备本地系统字体；没有外部 CDN 请求
- 音频只在首次用户操作后初始化；`localStorage` 读写有异常保护，只保存静音和最佳记录

### 2.3 工程

- 所有时间、伤害、速度、硬直、窗口、卡槽等参数集中在 `src/config/balance.ts`
- `tsconfig` 开启 `strict`、`noUnusedLocals`、`noImplicitOverride`；未使用 `any`
- 固定 HUD/触屏/答题层的点击区域统一 `scrollFactor(0)`，避免镜头滚动后点不中
- 构建脚本 `scripts/build.mjs` 将 esbuild 临时目录固定到项目内 `.tmp-esbuild/`，规避本机 Windows 临时目录权限导致的构建失败；该目录已忽略

## 3. 与设计文档的差异

原始设计文档保留在 `docs/开发文档.md`，未删除。以下为实现与设计的已知差异，均按“先交付可运行 MVP”原则处理：

| 项目 | 设计文档 | 当前实现 |
|---|---|---|
| 幕数 | 第一幕 + 第二幕（加时） | 仅第一幕，第二幕未开始 |
| 名字门数量 | 第一幕 2 道 | 第一幕 1 道 |
| 名字门答错 | 5 秒重试或“硬闯”触发小怪 | 30 秒窗口；答错可立即重试；“硬闯”未实现 |
| Boss 硬直 | 8 秒 | 3.2 秒（`BOSS.staggerMs`），保证节奏紧凑 |
| 弹反次数 | 每阶段一次 | 每阶段一次，共三次，随血量阶段推进 |
| 梗卡数量 | MVP 6 张 | 8 张（超出 MVP 要求） |
| 抽卡与卡槽 | 三选一 | 三选一；签收袋最多 3 张，满袋替换最旧卡；允许重复卡 |
| 第二幕 Boss | 荒哥 | 未实现 |
| 部署 | Qoder Sites public | 已生成静态构建产物，尚未部署 |
| 构建 | `npm run build` 直接调用 tsc/vite | 通过 `scripts/build.mjs` 包装，修复本机构建权限问题 |

## 4. 运行与构建

```bash
cd D:\jbcode\Qoder-competition
npm install
npm run dev        # 开发预览，默认 http://127.0.0.1:5173
npm run typecheck  # TypeScript 严格检查
npm run build      # 类型检查 + 生产构建，输出 dist/
npm run preview    # 本地预览 dist/
```

`vite.config.ts` 使用 `base: './'`，`dist/` 可作为纯静态目录部署；无任何跨域或服务端接口依赖。

### 操作

- 桌面：A/D 移动，空格二段跳，J 射击，K 冲刺，E 交互，1/2/3 认梗作答，Z/X/C 使用梗卡，M 静音
- 手机：左下角左/右移动，右下角射击/跳跃/冲刺/交互，答题与梗卡直接点选
- 手机建议横屏；竖屏会显示旋转提示
