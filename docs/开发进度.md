# 《浣熊火箭：无名氏危机》开发进度

- 更新时间：2026-11-19
- 当前版本：0.2.0（第一幕「发布会大厦」+ 第二幕「荒野岛」）
- 仓库：https://github.com/hahaandxixi/Qoder-competition

- 形态：Phaser 3 + Vite + TypeScript，纯静态站点，无后端、数据库、外部 CDN

## 1. 当前结论

两幕均已形成可玩的完整闭环：

**标题 → 第一幕跑跳/射击 → 代签单名字门 → 365 里路倒带名字门 → 奶娃主持人登场 → 三个阶段 → 第一幕结算 →「前往荒野岛」→ 取景框教学 → 亡命天涯名字门 → 这是好事呀名字门 → 荒哥登场 → 三个阶段 → 第二幕正式结算 → 重试 / 返回标题**

第一幕保留「代签单 → 365 里路 → 奶娃主持人」原体验与三连残影冲刺四拍音效。第二幕包含独立检查点、梗卡奖励、荒哥正式结算与失败重试，从第一幕进入、第二幕复活或重试时不会串用旧门状态。

`npm run typecheck` 与 `npm run build` 已在本机通过。第一幕已发布到 Qoder Sites（public）：https://raccoon-rocket-ajj0fzwid68.qoder.zone ；第二幕在当前协作分支完成本地构建与验收，尚未部署到 Qoder Sites。

## 2. 已实现内容

### 2.1 舞台与射击手感

- 保留左右移动、二段跳、土狼时间/跳跃缓冲、射击、冲刺（带无敌帧与残影）、梗卡与梗浓度槽
- Boss 房补了横版发布会舞台：褪色巨幕、快递传送带、升降台、讲台、垂下的卷曲面单；阿浣在左、演示物在中、甄领先在右
- 射击首次按下立即出弹，按住稳定连发，松开停火；枪口短闪、扇形弹道、命中闪白与音效沿用原系统
- 普通射击使用轻量反馈；完美弹反保留明显顿帧、震屏和闪白

### 2.2 第一道名字门「代签单」

- 收发室包裹、按铃、机器打印小票，答题时面单留在视野内
- 小票三行：收件人 甄领先 / 代签人 灭建国 / 与收件人关系 父
- 问题「谁替甄总签了包裹？」，选项含甄领先/灭建国/阿浣/收发员
- 答对盖「代签有效」，尾巴卷走签收联，门闩打开，进入原有三选一梗卡
- 答错可重试；门状态写入 `RunState.door1Passed`，检查点复活后仍可继续
- 这张签收联在 Boss 第二阶段重新展开

### 2.3 第二道名字门「365 里路」

- 玩家先看到近处取件窗口；按铃后窗口沿轨道滑远
- 吐出「取件请绕行 365 里」路线单，纸路一头连窗口、一头缠双轴磁带机
- 问题「按哪个键，能把这条路收回来？」，选项为播放/快进/倒带/录音
- 答对：线轴反转、纸路回卷、窗口拖回、取件铃响，窗口开成 Boss 房入口
- 各自记录 `door2Passed`、奖励、出生点与检查点状态；答错可重试
- 原创吐纸、滚轴、取件铃音效仍由 WebAudio 合成，无外部素材

### 2.4 奶娃主持人甄领先

- Boss 外观改为报废育儿打印机误打出的奶娃主持人：纸卷胎毛、快递面单围兜、倒扣周转箱、比头还大的方章
- 首次进房播放约 4 秒登场：
  - 闸门落锁、讲台亮灯、胎毛从周转箱后露出，音箱弹出「咔啵」「咔啵」
  - 奶娃指向阿浣腰间旧扫码枪，问「你是什么手机？」
  - 阿浣扫码「滴。」，巨幕印出「甄领先｜本场主讲人」，奶娃给自己补章，镜头拉回战斗
- 演出期间暂停伤害、攻击和 Boss 计时；空格或点击可跳过
- 自然播完与跳过共用 `finishIntro` 收尾；跳过输入被消耗，控制权恢复后才出首招预警
- 用 Registry 的 `bossIntroSeen` 区分首次与同局重试；从标题开始新局才清除
- 同局死亡 → 结算 → 重试直接回到 Boss 房，不再从关卡开头跑

### 2.5 两个梗的 Boss 招式

- 第一阶段 `radish_stamping`：机器人浇水、萝卜开花、巨章盖「类魂」并飘字「又是类魂」；演出结束后才出现三选一和 2 秒窗口
  - 答对：尾巴弹章、同一声扫码「滴」、「类魂」贴到围兜，浇水机转向奶娃；沿用反伤、硬直、掉卡
  - 答错/超时：沿用扣血、揭示答案和各自统计
- 第二阶段 `auto_signing`：宣布「全自动签收！」，三枚章依次举起，第一道门的小票重新展开
  - 问「代签人是谁？」，选项甄领先/灭建国/阿浣
  - 答对：尾巴展开签收单接住前两枚章，第三枚弹回围兜盖「已签收」；沿用反伤、硬直、掉卡
  - 答错/超时沿用原受伤与揭示逻辑
- 第三阶段保留原有高潮招式，未改写

### 2.6 三连残影冲刺四拍音效

- `dash_combo` 新增一组同源金属印章音效，全部由 `AudioSystem` 的 WebAudio 合成，不引入外部音频素材
- 第 1 拍是短促金属「当」，与 Boss 染色和「三连残影冲刺！」浮字同帧出现；后续三拍分别绑定三次冲刺真正启动的 `setVelocityX` 回调
- 中间两拍像公章擦过金属导轨，收尾拍更厚、尾音更长；四拍沿用同一组不和谐金属泛音
- 不改变攻击速度、伤害判定、冲刺间隔或躲避窗口；静音只关闭声音，染色、浮字和冲刺动作照常
- 硬直、特殊招、阶段转换、玩家/Boss 死亡和场景 shutdown 都会切断该组音效总线，后续拍点不再触发

### 2.7 第二幕「荒野岛」舞台与取景框教学

- 荒野岛为横向舞台，包含海雾、逆光、断桥和前后景平台；登陆点有被风吹向一侧的褪色防水布、挂在缆绳上的歪斜路牌、卡在远处树枝里的补给箱，以及第一幕用过的「已签收」箱盖
- 无人机先拍空箱：地面四角框合拢、快门「咔」、补给网只罩住空箱；第二个取景框转向阿浣，并留出移动/冲刺的预警时间
- 取景框同时用角框形状、合拢动作和文字标签表达，不只靠颜色；静音下仍可完整学习
- 被框罩住只锁一小段时间，不扣血；成功躲开有明确反馈。教学只在首道门未通过时播放，从检查点复活不会重复
- 新增补给搬运蟹：钳上顶着罐头盖，举盖蓄力后再突进；近距离射击可打断。举盖有空罐碰响，无人机有对焦/快门声
- 第一幕四拍金属音效仍是甄领先专属，第二幕不重复使用

### 2.8 第二道门之前的「亡命天涯」

- 荒哥在闸机旁录制逃生演示，立起「唯一退路」路牌；无人机拉紧缆绳，把荒哥和路牌一起拖出画面，地上刮出「亡命天涯」
- 问题「刚才路牌拖出了哪四个字？」；答对后阿浣抓住拖回来的缆绳，放下断桥
- 演出建立「缆绳绷紧＝正在拖拽」的规则，供 Boss 第二阶段复现
- 通过后写入 `RunState.act2Door1Passed`，解除断桥屏障，生成临时营地检查点，并进入三选一梗卡

### 2.9 「这是好事呀」货架门

- 雨棚漏水，水滴进空桶；演示中水桶变重，滑轮把挡路货架短暂吊起又落下
- 问题「荒哥说这是好事，究竟好在哪？」，选项中只有「水桶变重，吊起货架」成立，不依赖原梗背景也能推理
- 答对后桶标为「满桶」、货架升到顶部、碰撞屏障移除，生成第二个检查点并进入梗卡三选一；答错会重置演示水位和「空桶」状态
- 各门分别记录通过、奖励与检查点状态；从第一幕进入会清空第二幕门状态，第二幕复活保留已通过的门，不与第一幕的 `door1Passed` / `door2Passed` 混用

### 2.10 荒哥 Boss

- 三段阶段：第一阶段「镜头跟上」、第二阶段「亡命天涯」、第三阶段「这是好事呀」；Boss 总血量 720，阶段阈值为 100% / 66% / 33%
- 首次进房播放约 4 秒登场，可等完或按空格/点击跳过：
  - 镜头沿绷紧的缆绳移动，观众以为荒哥在另一端，实际只有纸板「荒哥正在抵达」
  - 真荒哥从下方爬上，扶正自拍杆；无人机对焦、快门一闪，弹出「荒哥 · 本期节目主持人」名牌
  - 跳过输入被消耗，镜头与 HUD 归位后才开战；同局重试不再播放
- 第一阶段：取景框扫向玩家，首轮合拢较慢（约 2.1 秒），之后约 1.65 秒；框合拢后补给网落下。另有营具抛掷作为普通攻击。持续射击、移动和冲刺沿用第一幕手感
- 第二阶段特殊招「亡命天涯」：缆绳绷紧，熟悉的路牌扫过舞台，随后弹出「路牌被缆绳拖走时，地上刮出哪四个字？」。答对后阿浣把绳扣挂上自拍杆，无人机拖走荒哥自己的营具，造成反伤与硬直并掉卡
- 第三阶段特殊招「这是好事呀」：雨棚漏水、满桶悬在荒哥上方，弹出「满桶悬在雨棚上方，阿浣该做哪一步？」。答对后放松滑轮，雨棚兜住荒哥，造成反伤、更长硬直并掉卡；第三阶段还会循环出现三处预警的水柱
- 弹反窗口约 2 秒，从选项可读且输入生效时开始；答错/超时沿用统一扣血与揭示逻辑。每个阶段的特殊招、反伤、硬直、奖励和音效只结算一次；反伤跨阶段时不会丢失已获得的卡
- 清空血条后，荒哥的手从雨棚里伸出，把「这是好事呀」翻到背面「本期拍摄完毕」，停顿约半拍后进入第二幕正式结算；失败结算后，已通过第二道门则重试直接回 Boss 房，否则回岛上检查点

## 4. 运行与构建

```bash
cd D:\jbcode\Qoder-competition
npm install
npm run dev        # 开发预览，默认 http://127.0.0.1:5173
npm run typecheck  # TypeScript 严格检查
npm run build      # 类型检查 + 生产构建，输出 dist/
npm run preview    # 本地预览 dist/
```

生产预览的自动验收可在地址后加 `?debug=1`；正常游玩不带该参数。

### 操作

- 桌面：A/D 移动，空格二段跳，J 射击，K 冲刺，E 交互，1/2/3 作答，Z/X/C 使用梗卡，M 静音
- 手机：左下角左/右移动，右下角射击/跳跃/冲刺/交互，答题与梗卡直接点选
- 手机建议横屏；竖屏会显示旋转提示

### 从首页玩到两个 Boss

1. 标题点开始，向右到收发室，按 `E`，答「谁替甄总签了包裹？」→ **灭建国**
2. 继续向右到取件窗口，按 `E`，看窗口滑远，答「按哪个键，能把这条路收回来？」→ **倒带**
3. 进 Boss 看完/跳过登场；第一阶段答 **类魂**，第二阶段答 **灭建国**，随后继续射击并清空第三阶段
4. 第一幕结算点「前往荒野岛」。登陆后看完取景框教学，首门答 **亡命天涯**，第二门答 **水桶变重，吊起货架**；荒哥战第二阶段弹反选 **亡命天涯**，第三阶段选 **放松滑轮，雨棚兜住荒哥**，清空血条后进入第二幕正式结算
